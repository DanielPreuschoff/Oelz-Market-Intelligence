# Impuls-Register

Fortlaufende Liste aller Produktkonzepte, die durch die Recherche gelaufen sind —
**auch die verworfenen**. Gleiche Mechanik wie das [Rohstoff-Register](rohstoff-register.md):

1. **Ausschlussliste für die Läufe.** Der Platzhalter `{BEKANNT}` in
   `prompts/produkt-marktscan.md` und `prompts/produkt-transfer.md` wird aus der
   Spalte „Konzept" gefüllt. Ohne das liefern die Dienste jeden Monat den Crookie.
2. **Gedächtnis für Verworfenes.** Mit Begründung, damit dieselbe Sackgasse nicht
   zweimal recherchiert wird.

Besonderheit gegenüber dem Rohstoff-Register: Ein Konzept kann **wiederkommen** —
nämlich dann, wenn es eine weitere Marktgrenze überschreitet. Der Transferradar-Prompt
erlaubt das ausdrücklich; im Register bekommt das Konzept dann eine neue Zeile mit dem
neuen Sprung, die alte bleibt stehen.

Wird beim Aufbereiten der Berichte fortgeschrieben, nicht von Hand gepflegt.
